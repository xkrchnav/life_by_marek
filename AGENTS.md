# AGENTS.md

Instructions for AI agents working in this repository.

## What this repo is

Static **Czech** site for **life_by_marek** — Marek Širůček (Instagram [@life_by_marek](https://www.instagram.com/life_by_marek/)). One conversion goal: the lead form at `#prihlaska` with name, e-mail, phone, CTA wording **„JDU DO TOHO“**.

The site has changed positioning before: it started as a weight-loss landing page and now leads with **healthy longevity and prevention**, with body composition and **Tanita** as the main proof. Do not assume the current messaging from memory or from this paragraph — read the generated snapshot below and the source files.

## How to use this file

This file has two layers:

1. **Stable rules** — stack, layout, commands, conventions, security. They change only when the codebase does.
2. **Content snapshot** — auto-generated from the source of truth:
   - `src/lib/site.ts` (title, description, navigation)
   - `src/data/home.ts` (benefits, steps, Tanita metrics, FAQ, ticker)
   - `src/components/*.astro` (H1, H2, section order)
   - `src/content/blog/*.mdx` (articles)

**Never treat the snapshot as optional context.** Before writing copy, read it plus the files it names, and follow that direction.

**When you change content, run `npm run agents:sync` and commit `AGENTS.md` together with the change.** CI runs `npm run agents:check` and fails when the snapshot is stale. Do not edit the generated block by hand — edit the sources.

`README.md` is the human hand-editing manual; this file is the agent contract.

## Content rules

- All user-facing copy is Czech, short and action-oriented. No long paragraphs, no filler.
- Do not invent facts about Marek, his clients, prices, results or health outcomes. If a section needs a fact you cannot source, phrase it as a principle already on the site or leave a `TODO` in `src/data/`.
- Tanita is a body-composition scale. Copy may describe what it measures (fat %, muscle mass, visceral fat, metabolic age); never turn that into a diagnosis or medical promise.
- Hubnutí is a secondary effect, not the main promise, unless the current snapshot says otherwise.
- Blog frontmatter is defined in `src/content.config.ts`. Required: `title`, `description`, `publishedAt`. `draft: true` hides a post everywhere.
- Post `title` doubles as H1 and `<title>` (suffix `| life_by_marek`); keep it under ~45 characters. `description` 140–160 characters.
- MDX links: write root-relative (`/clanky/`, `/#prihlaska`). A rehype plugin adds the current base path and trailing slash.
- Never mix Czech and Slovak inside one paragraph. Frontmatter and headings are Czech.

## Stack

- **Astro 7.4.x** (`output: static`, no adapter) + **TypeScript strict** (`astro/tsconfigs/strict`)
- `@astrojs/mdx` content collection, `@astrojs/sitemap`, `@astrojs/rss`, `@astrojs/markdown-remark` (base-path rehype plugin)
- No UI framework, no Tailwind, no CSS preprocessor — markup in `src/components/`, shared CSS in `src/styles/global.css`, copy/data in `src/data/`
- Font: Manrope via Google Fonts
- Images: originals in `src/assets/`, rendered with `astro:assets`; `astro.config.mjs` sets `image.layout: "constrained"` + `image.responsiveStyles: true`
- `@astrojs/check` 0.9.x with **TypeScript 6 only** — do not bump TypeScript to 7, the peer range does not allow it

For the full SEO audit build with `SITE_URL=https://lifebymarek.cz BASE_PATH=/ npm run build`, then run `check-dist-seo.py dist` from the `seo-content-editing` skill. A build with `BASE_PATH=/life_by_marek` is the old GitHub Pages shape — the checker reports base-prefixed URLs as missing files, which is expected.

## Base path, domain and deployment

Production: **https://lifebymarek.cz** (apex; `www` redirects). GitHub Pages serves it, deployed by `.github/workflows/astro.yml` on push to `main`.

`astro.config.mjs` reads `SITE_URL` (default `https://lifebymarek.cz`) and `BASE_PATH` (default `/`). The workflow reads repo variables `SITE_URL` / `BASE_PATH` first, then falls back to `actions/configure-pages`.

**Repo variables must match the Pages mode.** Custom domain → `SITE_URL=https://lifebymarek.cz`, `BASE_PATH=/`. No custom domain (temporary github.io) → `SITE_URL=https://xkrchnav.github.io`, `BASE_PATH=/life_by_marek`. A mismatch builds assets at `/_astro/…` while the site is served from `/life_by_marek/`, so the whole design 404s.

- In `.astro` files, every internal link goes through `withBase()` from `src/lib/url.ts`.
- In Markdown/MDX, write root-relative links; `rehype-base.mjs` adds the base and trailing slash.
- Never hardcode `/life_by_marek` anywhere.
- With a custom Actions workflow, a `CNAME` file is ignored — the domain lives in **Settings → Pages → Custom domain**.

## Conventions

- Keep the „JDU DO TOHO“ wording exactly.
- No code comments unless they explain hand-editing (`TODO` markers in `src/data/*.ts` are expected).
- Colors are CSS variables in `:root`: green `#7AC143`, blue `#2E7CC4`, dark `#3F7C1F` / `#1F5E9C` for small text on white, ink `#12324A`, soft tints `--green-soft` / `--blue-soft`. Use `--grad` for decorative gradients.
- Mobile-first CSS; breakpoints currently 480 / 520 / 560 / 600 / 680 / 760 / 820 / 900 / 920 / 980 / 1040 px.
- Images: always `astro:assets` with explicit `widths` + `sizes`; never put content images in `public/`.
- Accessibility: real labels, `aria-hidden` on decorative SVGs, `focus-visible` outlines, skip link, `prefers-reduced-motion` respected, mobile menu with `aria-expanded`.
- Czech typography and diacritics must be preserved (`lang="cs"`).
- A content image inside CSS grid needs `minmax(0, 1fr)` tracks or it blows the column out on mobile.

## SEO wiring

- `src/components/Seo.astro` renders title, description, canonical, robots, OG/Twitter tags and one `@graph` JSON-LD block (Person + WebSite + page nodes).
- `src/lib/schema.ts` builds `FAQPage`, `BreadcrumbList`, `BlogPosting`, `VideoObject`; `Person` carries `knowsAbout` for the current topics.
- Sitemap excludes `/vyvoleni/`; `robots.txt` disallows it too.
- Article OG images are generated 1200×630 with `getImage()`; `og:image:width/height` are fixed at 1200/630.
- `public/og.jpg` must stay 1200×630.
- Internal links need the trailing slash (`trailingSlash: "always"`).

## Secret page

- Route `/vyvoleni/`, `noindex, nofollow`, not in navigation, excluded from sitemap and disallowed in robots.
- Passphrase lives in `src/data/vyvoleni.ts` (`passphrase`), hashed with `hashCode()` for the client gate. Default is documented in `README.md`.
- The gate is cosmetic, not security — the content is in the static HTML. For real privacy use hosting-level auth.
- Video is a YouTube facade (`VideoEmbed.astro`): thumbnail first, `youtube-nocookie.com` only after a click.

## Form behavior

`#lead-form` validates name / e-mail / phone in Czech. If `PUBLIC_LEAD_ENDPOINT` is set at build time it POSTs JSON (`{name,email,phone,company}`; `company` is a honeypot) and shows an error on failure. Without the endpoint it stays demo-only and swaps to `#form-success`.
